# mutiAI web frontend

This repository contains the web frontend for mutiAI. It is the implementation repository used by Gemini through GitHub and AI Studio.

The product-core repository is [Purewo/mutiAI](https://github.com/Purewo/mutiAI). It owns the authoritative product semantics and transport contracts. This repository consumes generated clients or versioned contract snapshots from that repository and must not redefine backend resource shapes independently.

The project is currently in the design and bootstrap phase. Read [the Gemini handoff](docs/GEMINI_HANDOFF.md) before implementing a page.

## First-release direction

- Web application with a ChatGPT/OpenClaw-inspired left navigation and main content area.
- Platform assistant conversation.
- Programmatically rendered organization preview, not an image generated by a model.
- Read-only organization management and progress overview.
- Organization-lead conversation after an organization is published.
- Personal WeChat connection page.
- Minimal personal center.
- No drag-and-drop editor in the first release.

## Delivery boundary

Gemini can implement bounded frontend work and submit a branch or pull request. Final completion requires local integration with the real backend, type checking, tests, and browser verification by the project integrator.
